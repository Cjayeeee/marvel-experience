# Character artwork

Put one image per character in this folder, named after its slug, for example `iron-man.webp`.
File names are not case-sensitive, and common alternates like `spiderman`, `mr-fantastic`, `thing`, `yelena` and `winter-soldier` also work.
Accepted formats: .jpg, .jpeg, .png, .webp, .avif. Portrait images around 900×1200 (3:4) look best.
Images are picked up automatically the next time the dev server reloads or the site builds.
Characters without an image keep their styled placeholder.
